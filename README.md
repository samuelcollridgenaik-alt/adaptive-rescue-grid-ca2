# Adaptive Rescue Grid — Intelligent Rescue Navigation Using SARSA and Q-Learning

CA-2 project for **Presidency University**, MCA Semester III, **CSA4708 Reinforcement Learning**, Module 3: **Temporal Difference Learning**.

[![Validate application](https://github.com/samuelcollridgenaik-alt/adaptive-rescue-grid-ca2/actions/workflows/ci.yml/badge.svg)](https://github.com/samuelcollridgenaik-alt/adaptive-rescue-grid-ca2/actions/workflows/ci.yml)

Adaptive Rescue Grid is a responsive React command-center simulation in which a rescue robot learns to reach a destination through walls and hazards. It is deliberately built as a live teaching application: the grid, rewards, Q-table, learned policy, reward curves and comparison all use the same tabular learning engine.

## The one concept to emphasise

For a short team presentation, focus on **TD control in a hazardous map**:

- SARSA is **on-policy** because its update uses the next epsilon-greedy action actually selected: `Q(s,a) ← Q(s,a) + α[r + γQ(s′,a′) − Q(s,a)]`.
- Q-Learning is **off-policy** because it uses the greedy next-state value: `Q(s,a) ← Q(s,a) + α[r + γ max_a′ Q(s′,a′) − Q(s,a)]`.
- On a terminal goal or terminal hazard, the bootstrap value is exactly zero, so the TD target is only the immediate reward.
- The cliff-side map is an example that can expose different risk behaviour under persistent exploration. It does **not** establish an always-better algorithm.

## Application capabilities

- Customizable grid dimensions with robot, rescue destination, walls, hazards and eraser tools.
- Manual controls via on-screen pad, arrow keys or WASD.
- Seeded, reproducible SARSA and Q-Learning training sessions with start, pause, reset and speed controls.
- Configurable learning rate, discount, epsilon schedule, episode count and step cap.
- Real-time reward, steps and success-rate charts; Q-table inspection; policy arrows; greedy-route replay.
- Fair comparison: each side begins from a fresh Q-table under the same map, seed and parameters.
- Scenario presets, including a hazardous cliff-side evacuation comparison.
- Responsive layout for desktop and mobile.

## Actual experiment used in the slides

The results are not fabricated: `presentation/experiment-results.json` is generated by the project’s own training engine.

- Map: 12 × 4 cliff-side evacuation grid; lower-row hazards reset the robot.
- Runs: 5 matched seeds, 300 episodes/seed, 160-step cap.
- Parameters: α = 0.5, γ = 1.0, persistent ε = 0.1.
- Fairness: fresh zero Q-table for each algorithm/run; same seeds, rewards, map and episode cap.
- Final rolling reward: SARSA **59.7 ± 19.9**; Q-Learning **59.4 ± 12.7**.
- End-window success: SARSA **97.3 ± 5.3%**; Q-Learning **100.0 ± 0.0%**.

Treat these figures as configuration-specific evidence, not a universal ranking.

## Live demo flow (about 2 minutes)

1. Select **Cliff-side evacuation comparison** and explain the lower hazard strip.
2. Make one manual move using the visible pad.
3. Select SARSA, keep the seed visible, start training and pause briefly.
4. Point to one Q-table row, a reward/success chart and the terminal bootstrap note.
5. Replay the learned route, then choose **Fair compare**.
6. State that both algorithms receive fresh Q-tables and matched conditions.
